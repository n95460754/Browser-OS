# ◆ NovaOS — операционна система в браузъра

Работен плот, прозорци, лента на задачите и приложения. Само HTML + CSS + JavaScript, без библиотеки и без build стъпка.

## Стартиране
Отвори `index.html` в браузър. Или включи **GitHub Pages** (Settings → Pages → branch) и ще работи и от телефона.

## Теми (Настройки → Тема на прозорците)
**Класик** (стил 2001) · **Стъкло** (стил 2009) · **Плосък** (стил 2015) · **Нова**. Оригинален дизайн, вдъхновен от тези епохи.

## Приложения
📁 Файлове · 💻 Терминал (`help`) · 📝 Бележник (Ctrl+S) · 🧮 Калкулатор · 🎨 Рисуване · 🌐 Браузър · ⚙️ Настройки · 🖼️ Снимки

## Игри
| Игра | Управление |
|---|---|
| 🃏 Пасианс | докосни карта → докосни къде отива; втори път = към базата |
| 🪩 Пинбол | ← / → флипери, задръж Space и пусни за изстрел |
| 👾 Подземие 3D | W/A/S/D, Space стрелба; намери зелената врата (2 нива) |
| 💣 Сапьор | клик отваря, десен клик / дълго задържане = знаменце |
| 🧱 Блокчета | ← → ↑ ↓, Space пускане |
| 🏓 Тухли | мишка/пръст или ← →, Space старт |
| 🐍 Змия | стрелки или плъзгане |

Всички игри имат бутони на екрана за телефон.

## Как е направена
- `os.js` — виртуална файлова система (пази се в `localStorage`), мениджър на прозорци (влачене, преоразмеряване, минимизиране), старт меню и всички приложения.
- `skins.css` — четирите теми. `games.js` + `games.css` — игрите (регистрират се през `NovaOS.register`).
- `style.css` — основният вид (тъмна/светла, цветове, тапети).
- В DevTools конзолата: `NovaOS.apps.snake.open()`.
